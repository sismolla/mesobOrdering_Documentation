**URL:** `/cashier/history` **Access:** Click **History** in the cashier navigation.

## Overview

The History page shows all **completed (paid) bills** as a searchable list.

## History table columns

| Column | Description |
| --- | --- |
| **Date / Time** | When the bill was paid |
| **Table** | Table number |
| **Session ID** | Short reference |
| **Total Paid** | ETB amount collected |
| **Payment Method** | Which bank/provider was used |
| **Processed By** | Which cashier confirmed the payment |
| **Status** | PAID (green) |

## Filtering history

Use the available filters to find specific transactions:

- **Date range picker** — Filter by day, week, or custom range
- **Table number** — Filter by a specific table
- **Search** — Search by session ID or amount

## Viewing a past bill

Click any row in the history table to see the full bill breakdown:

- Itemized receipt
- Tax and service charge details
- Payment method used
- Timestamp and cashier name
