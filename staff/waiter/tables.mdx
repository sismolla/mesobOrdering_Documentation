**URL:** `/waiter/tables` **Access:** Click **Tables** in the waiter navigation.

The Tables page shows all tables in the restaurant and their current occupancy status.

## Table status overview

Tables are displayed as visual cards or a list. Each table shows:

| Info | Description |
| --- | --- |
| **Table Number** | e.g. "Table 5" |
| **Status** | Available (green), Occupied (blue/orange), or Reserved |
| **Guest Count** | Number of guests currently seated |
| **Session Duration** | How long the current session has been open |
| **Total Bill So Far** | Running total for the active session |

## Table actions

For each occupied table:

- **View Table** — See all orders placed by this table in the current session
- **Place Order** — Navigate to the Place Order page pre-filled with this table's token
- **Request Bill** — Initiate the billing process for this table

## Filtering tables

Use the filter tabs or dropdown to view:

- **All Tables** — Every table in the system
- **Occupied** — Only tables with active guest sessions
- **Available** — Empty tables ready for guests
