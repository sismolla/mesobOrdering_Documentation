**URL:** `/bar/dashboard` **Access:** Default landing page after bar staff login, or click **Dashboard** in bar navigation.

The Bar Dashboard is the home screen for bar staff, giving a quick overview of current bar activity.

## Layout

The Bar layout has a navigation menu with:

- **Dashboard** — Overview and stats
- **Display** — The live order queue
- **History** — Past bar orders

## Dashboard stats

Summary cards showing bar performance:

| Card | Description |
| --- | --- |
| **Active Bar Orders** | Number of drinks currently being prepared |
| **Pending** | Orders received but not yet started |
| **Completed Today** | Total bar orders completed this shift |
| **Revenue Today** | Total ETB from bar orders today |

## Recent bar orders

A list or table of the most recent bar orders with:

- Order ID
- Table Number
- Items ordered (drinks list)
- Status
- Time placed

## Quick actions

Direct buttons to:

- **View Order Queue** — Go to the [Bar Display](/staff/bar/display)
- **View History** — Go to [Bar History](/staff/bar/history)
