This glossary defines the core terms you'll encounter throughout MesobOrdering and its documentation. Whether you're setting up your hotel for the first time or training new staff, these definitions will help you and your team speak the same language when using the platform.

## Terms

| Term | Definition |
|---|---|
| **Session** | A guest's active table visit, from QR scan to bill payment. A session is tracked separately from the individual orders placed within it. |
| **Order** | A set of items a guest submits from the menu. A single session can contain multiple orders placed at different times during the visit. |
| **ETB** | Ethiopian Birr — the currency used throughout MesobOrdering for all pricing, payments, and revenue figures. |
| **Department** | The preparation station assigned to a menu item: either **Kitchen** or **Bar**. The department setting determines which order queue receives the item when a guest places an order. Items without a department assigned route to the Kitchen by default. |
| **Stamp** | A loyalty unit collected by a guest per qualifying visit or order. Stamps accumulate toward a reward threshold defined in a loyalty program. |
| **Redemption** | The event when a guest exchanges their accumulated stamps or visits for a loyalty reward. Redemptions can be triggered automatically at the threshold or manually by a staff member from the Guests tab. |
| **Dynamic Pricing Rule** | A scheduled price adjustment — expressed as a percentage or a fixed ETB amount — that is applied automatically to selected menu items during specific times and days. |
| **Audit Log** | A chronological record of every significant staff action taken on the platform. Used for oversight, accountability, and fraud detection. |
| **Risk Level** | A classification of how suspicious a recorded staff action is, assigned automatically. Levels are **Low**, **Medium**, **High**, and **Critical**. |
| **Page Gate** | The feature that allows you to enable or disable specific pages for guests or staff through the Page Manager. Disabling a page hides it from users without removing its configuration. |
| **Telegram Link Code** | A 6-digit code generated in System Config → Alerts that you send to @AlphaBotServiceBot on Telegram to connect your hotel's admin account to the bot. Codes expire after 10 minutes. |
| **SSID** | The Wi-Fi network name displayed to guests on the digital menu. You set this in **System Config → Identity** so guests can easily connect to your hotel's network. |
| **Completion Rate** | The percentage of table sessions that resulted in a paid bill. Displayed in the Analytics section as a measure of guest conversion. |
| **Avg Ticket** | The average monetary value of a single order, shown in the Analytics section. Useful for tracking spending trends over time. |
| **MVP** | Short for **Most Valuable Product** — the single top-earning menu item highlighted in the Strategic Insights panel of Analytics. |
